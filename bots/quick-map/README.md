# Quick Marketing Map

This folder is the complete Vercel project for the Quick Map chat.

- index.html is the browser interface.
- assets contains the logo and favicon.
- api/chat.js keeps the Anthropic key private and runs the guided conversation.
- .env.example lists the Vercel environment variables.
- vercel.json contains function and security settings.

Vercel Root Directory: bots/quick-map

Required environment variable: ANTHROPIC_API_KEY
